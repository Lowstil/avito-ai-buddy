# SDD-05: Product Metrics & Evaluation Specification
## Avito AI-Buddy (Hack&Change 2026)

### 1. Business Problem & Opportunity
По данным кейса Авито:
* За 6-месячную программу стажировки наставник тратит **40–48 часов** времени.
* За 9-месячную программу стажировки — **55–65 часов** времени.
* Значительная часть этого времени уходит на повторяющиеся организационные вопросы (оформление отгулов, поиск документации, запрос доступов, напоминание этапов чек-листа).

### 3. A/B Testing & Pilot Rollout Methodology
Для валидации эффекта на реальных стажёрах Авито предлагается двухкогортный пилот:
1. **Когорта A (Контрольная, 40 стажёров):** Традиционный онбординг (чек-лист в Google Sheets, коммуникация только через личные сообщения бадди в Slack/Mattermost).
2. **Когорта B (Тестовая, 40 стажёров):** Онбординг с поддержкой Avito AI-buddy (интерактивный трекер + AI-ассистент с MCP-сервисами).

**Методика замера:**
* Хронометраж менторов (еженедельный self-report + данные встреч в календаре).
* Clickstream-телеметрия: количество запросов к AI-buddy, типы закрытых тикетов без привлечения наставника.
* Длительность адаптационного периода до первого релизного PR в основной репозиторий.
