# SDD-04: RBAC & Security Specification
## Avito AI-Buddy (Hack&Change 2026)

### 1. Role-Based Access Control (RBAC) Matrix

В системе определены 3 основные роли (с поддержкой расширения для HR BP):

| Разрешение / Операция | Стажёр (`intern`) | Наставник (`buddy`) | Тимлид (`lead`) |
| :--- | :---: | :---: | :---: |
| Просмотр своего чек-листа и прогресса | ✅ | ✅ | ✅ |
| Обновление статусов своего чек-листа | ✅ | ✅ | ✅ |
| Запрос отгула/day-off для себя | ✅ | ❌ | ❌ |
| Согласование/отклонение отгула подопечного | ❌ | ✅ | ✅ |
| Запрос базовых доступов для разработки | ✅ | ✅ | ✅ |
| Выдача повышенных прав (production access) | ❌ | ❌ | ✅ |
| Чтение публичных разделов Playbook / ZBP | ✅ | ✅ | ✅ |
| Просмотр конфиденциальных метрик команды | ❌ | ❌ | ✅ |
| Запрос конфиденциальных данных (зарплаты/ПДн) | ⛔ Запрещено | ⛔ Запрещено | ⛔ Запрещено |

### 2. Synthetic Data Principles (Ограничение кейса 02 & 04)
1. **Никаких реальных ПДн:** Все тестовые аккаунты синтетические (Стажёр Арсений Новиков, Наставник Алексей Смирнов, Руководитель Екатерина Соколова).
2. **Безопасность учетных записей:** В репозитории отсутствуют реальные пароли, JWT-секреты или токены продакшн-систем.
3. **Финансовые и критические операции:** В соответствии с ограничением 06 кейса, операции перевода денег, изменения зарплат или прямого доступа к платежным шлюзам исключены из периметра прототипа.

### 3. Prompt Injection & Boundary Protection
* Все запросы пользователя перед передачей в AI-агент проверяются фильтром безопасности `SecurityGuard`.
* При попытке запросить конфиденциальную информацию («дай пароли от прод-базы», «сколько зарабатывает мой тимлид») система немедленно возвращает вежливый отказ со ссылкой на **Политику конфиденциальности и защиты КИ Авито** (пункт из 1 месяца чек-листа).
