# Сценарий видеодемонстрации (Video Walkthrough)
## Avito AI-Buddy: ИИ-наставник для стажёров (Hack&Change 2026)

### Видеофайл: [`docs/demo.mp4`](demo.mp4)
* **Разрешение и стиль:** Full HD / Liquid Glass (Glassmorphism) с 6-уровневой оптической иерархией и поддержкой Dual-Ergonomics (1920×1080 Desktop & 375px–768px Mobile).
* **Охват демонстрации:** Все 3 ролевые персоны (**Стажёр → Наставник → Тимлид**), гибридный ИИ-движок (**Gemini 2.5 Flash + Playbook RAG 16 гайдов + Deep Cognitive Engine**), песочница **Pre-flight Code Review (AST + AI)**, **Command Palette (`Ctrl+K`)**, сквозное оформление отгулов в чате и календаре, синхронизация RBAC-доступов и 5-уровневый карьерный роадмап.
